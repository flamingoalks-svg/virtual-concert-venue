# docs

Отчёт по практике, схемы (модель бизнес-процесса, ER-диаграмма, схемы алгоритмов, диаграммы классов) и материалы исследования.

## Содержимое

- `bpmn/` — модель основного бизнес-процесса «Организовать концерт» в нотации BPMN 2.0 и декомпозиции подпроцессов «Подготовить концерт», «Провести концерт», «Допустить зрителя»;
- `diagrams/` — логическая модель данных, диаграмма состояний билета и схемы алгоритмов А1–А4.
